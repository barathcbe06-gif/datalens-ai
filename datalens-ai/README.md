# DataLens AI — Futuristic Homepage

## Run in VS Code

1. Extract the ZIP.
2. Open the `datalens-ai` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:
   npm install
5. Then:
   npm run dev
6. Open the local URL shown by Vite.

## Routes / integration

The demo launch button currently navigates to `/analyze`. Replace or extend the route with your real Analyze Dataset page/backend integration.

This starter is intentionally focused on the homepage visual system: Data Universe, Data Core, Chaos → Clarity, Data DNA, Intelligence Layers, Ask Your Data, ML flow and final Data Core.

## Stack
React + Vite + Framer Motion + Lucide React + React Router.
