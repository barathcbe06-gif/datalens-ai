DataLens AI 📊🤖

DataLens AI is a postgraduate academic project focused on combining Artificial Intelligence and Data Science to make data analysis and visualization more accessible through a web-based platform.

⚙️ Getting Started

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/datalens-ai.git

2. Navigate to the project

cd datalens-ai

3. Install dependencies

npm install

4. Start the application

npm run dev

The application will be available at the local URL provided by the development server.
